# macOS icon artwork

Generated with the built-in imagegen tool. `app-icon.png` is the original artwork with alpha transparency and is not included in the app bundle. `DictationHotkey.icns` contains palette-compressed macOS app icon resolutions, and `menu-icon.png` is the 36-pixel menu-bar asset. Regenerate both with `python3 tools/generate_macos_icon.py` on macOS with ImageMagick installed.

## Generation prompt

Use case: logo-brand
Asset type: macOS application icon for Dictation Hotkey, a voice-to-text dictation utility.
Primary request: create one polished colorful app icon, square 1024 x 1024. A bold ivory white microphone silhouette with a simple curved stand, subtly suggesting a speech bubble, centered on a luminous saturated cobalt-blue to violet gradient rounded-square tile with a small warm coral accent on the microphone. Friendly, crisp, premium, dimensional but clean; restrained soft highlights and shallow depth, no busy details. Strong readable silhouette at 16 and 32 pixels. Tile occupies about 88 percent of canvas, generous rounded corners, centered with transparent space outside the tile. Front view, symmetrical, no perspective.
Constraints: only one icon, no text, no letters, no watermark, no mockup, no surrounding scene. Actual transparent background outside the rounded-square tile.
